## 1. 愿景与定位

**一句话愿景**：一个运行在本地、有长期记忆的私人学习老师——它陪你学、帮你整理、看得见你的成长、在你遗忘前悄悄考你，像一个真正无微不至、又顺你心意的老师。

**核心定位**：

- **私有**：所有数据在本机，断网可用，无人能看，可随时导出 / 备份 / 迁移
- **有记忆**：AI 助教不是每次"失忆重来"，而是越来越懂你
- **看得见成长**：学习过程不是黑盒，而是可回放、可追溯、可量化的成长史

**目标用户**：以计算机在校学生、初学者为主，兼顾转行、在职提升、备考求职等身份。

---

## 2. 核心设计理念（固定底座）

固定底座是产品的"存在方式"，是固有机制而非用户可选项：

### 2.1 三大隐性内核

| 内核 | 含义 | 作用 |
|------|------|------|
| **隐性感知** | 从行为（答题对错 + 响应时间）推断记忆强度，而非让用户自评 | 让"无微不至"有数据来源 |
| **单源卡片** | 术语 / 会话 / 知识点是同一张卡片，在多视图被"引用"而非复制 | 多视图数据永远一致 |
| **记忆贯穿** | 所有模块共享同一个"懂你"的大脑，读写同一份记忆 | 模块间形成闭环 |

### 2.2 数据原则：可记录、可溯源、可分析

- **可记录**：一切学习行为写入不可变事件流（Event Sourcing）
- **可溯源**：任何知识点都能回放"我当初怎么学会它的"
- **可分析**：成长曲线、遗忘曲线、知识盲区，都可从事件流聚合得出

## 4. 八大功能模块

### 4.1 聊天学习（输入 + 沉淀）

- **工作区**：一个工作区 = 一个学习主题，内含多条会话
- **术语标注**：对话中的技术名词自动高亮，悬停速查一句话解释
- **派生会话**：快捷键一键派生子会话专门解释某术语，形成会话树（主从 / 父子 / 兄弟关系）
- **悬停弹窗**：含"分支会话 / 新会话 / 追问"等选项

### 4.2 学习资料 / 笔记（沉淀 + 回顾）

- 整个工作区可一键总结成结构化学习笔记（核心概念、术语表、代码示例、"我还未懂的点"）
- 笔记可导出（本地 Markdown）、可回看
- 笔记 ↔ 会话双向溯源：点笔记任意一句话跳回当初那次会话
- **笔记反哺**：笔记可一键变回复习卡、变出测试题、成为下次对话的上下文

### 4.3 白板（一板两用）

同一套"节点-连线"可视化引擎，两个视图：

| 视图 | 画什么 | 解决什么 |
|------|--------|----------|
| 会话关系图 | 工作区内的会话树（主从 / 父子 / 兄弟 / 派生） | "我聊了哪些、它们什么关系" |
| 个人成长地图 | 岗位能力树 + 掌握度热力 | "我在领域里走到哪了、下一步学什么" |

### 4.4 面试问答（检验 + 输出）

- 模拟面试：依据用户画像（薄弱点、错题史）针对性提问
- 分层判分：答对推进难度、答错降级到前置知识
- 错题回挂：答错的题关联到术语 → 一键去学习模块补知识点
- 风格化：提问方式随老师风格变化（严师压 vs 陪伴柔）

### 4.5 隐性巩固（对抗遗忘）

- **隐性出题**：不是用户主动选择才生成，而是记忆层根据画像在恰当时候悄悄考
- 触发时机：学完某术语后、遗忘临界点、面试答错的点几天后重现
- 答对 → 掌握度升级、复习延后；答错 → 降级、重新入队
- **复习精细化**：复习卡区分状态（新 / 学 / 复习 / 重学），按钮显示预测下次时间，目标保留率默认 85%

### 4.6 成长分析（洞察）

- 成长仪表盘：新掌握术语数、面试得分趋势、学习时长、活跃时段
- 成长曲线：掌握度随时间的变化
- 遗忘预警：预测哪些术语快忘，主动推送复习
- 学习路径推荐：基于前置依赖 + 掌握度，推荐"下一步学什么"

---

### 4.7 资源库（输入：学什么料）

- 资源库：教程 / 官方文档 / 书籍 / 视频 / 博客 / GitHub 项目，按岗位、知识点、术语组织
- 资源关联：每个术语/知识点关联对应资源（学 DNS → RFC1035、MDN、一篇好文章）
- 智能推荐：基于画像推荐下一步该看什么
- 收藏与标注：用户标想读/在读/已读，记笔记
- 单源卡片：同一资源被多术语引用，而非各存一份链接
- 内容来源：LLM 种子库 + 对话沉淀 + 用户手动添加（人工审校兜底）

### 4.8 环境 / 实践区（动手：学了会用）

> **已于 2026-08-15 下线、2026-08-24 正式除名**：SQL 沙盒页面、挑战库与校验器移除，历史练习事件与 Attempt 数据保留于分析证据流；"动手检验"由结构化面试承接。以下为愿景原文，仅作历史记录。

- 代码实践区：内嵌编辑器 + 运行按钮，学算法/语言时随手跑代码
- 环境搭建引导：检测本机已装版本 → 逐步指引（治"环境搭不起来"）
- 实验沙盒：练 SQL、Linux 命令、网络实验，隔离环境随便试错
- 分级策略：轻量练习用 WASM 沙盒（Pyodide / sql.js，零安装、断网可用、安全）；完整项目用本机环境检测 + 搭建引导（后置）
- 实践写进记忆：跑代码/做实验记入事件流（code_run / experiment_done），纳入成长分析

## 5. 老师风格系统

产品不预设一种老师，而是给用户一套可选风格，可全局设、可临时切、可绑定场景。

| 风格 | 人格定位 | 行为特征 | 适合谁 |
|------|---------|---------|--------|
| 苏格拉底式 | 引导者 | 反问、追问、让你自己想，不给答案 | 有基础、想深度思考 |
| 讲师式 | 系统讲授者 | 结构化、由浅入深、直接讲透 | 零基础、想快速建立框架 |
| 费曼式 | 检验者 | "用你的话讲给我听"，逼你复述查漏洞 | 想确认是否真懂 |
| 实战式 | 工程师 | 边写代码边讲、给最小可运行示例 | 想动手、项目导向 |
| 陪伴式 | 温柔同行者 | 耐心、鼓励、照顾挫败情绪 | 零基础、容易焦虑 |
| 严师式 | 高压面试官 | 犀利、push、高标准、追问到底 | 备考面试、想抗压 |

**风格影响面**：聊天学习的讲解方式、面试的提问与反馈、隐性出题的措辞与难度、笔记总结的口吻与详略。

**风格使用层次**：
1. 全局默认（设一个主风格）
2. 场景绑定（默认"学习=讲师、面试=严师、复习=陪伴"，可改）
3. 临时切换（会话中途一句话切换）

**风格推荐**：系统基于画像推荐（零基础 → 陪伴式、临近面试 → 严师式），用户可随时推翻。

| 内容深浅 | 一句话 / 详解 / 带代码 | 决定解释颗粒度 |

## 7. 成长闭环模型

```
  发现        学习        检验        掌握        巩固        应用
遇到陌生术语 → 悬停/派生会话 → 费曼复述/面试 → 标记已get → 间隔重复复习 → 面试实战/关联新知识
   │            │            │           │           │          │
   ▼            ▼            ▼           ▼           ▼          ▼
 [term_seen] [term_explained] [attempt] [mastered]  [reviewed] [attempt]
   └──────────────── 全部写入事件流，形成个人成长时间轴 ────────────────┘
```

- 微观周期：一次对话里"遇到→弄懂"一个术语
- 中观周期：一个知识点从"见过→掌握"（跨多天，含复习）
- 宏观周期：一个技术栈/岗位方向从"入门→精通"（跨多周，聚合多知识点）

---

> 完整学习链路：**资源输入**（查资源/看教程）→ **环境动手**（跑代码/做实验）→ 发现 → 学习 → 检验 → 掌握 → 巩固 → 应用，全部写入事件流。

## 8. 目标覆盖谱系

**身份维度**：在校生（各年级）、应届求职、转行、在职提升、准备实习 / 保研 / 考研

**岗位方向维度**（能力树，内置多棵，可扩展）：

- 后端 / 前端 / 算法·AI / 大数据 / 测试·QA / 运维·SRE / 客户端·移动 / 嵌入式 / 网络安全 / 游戏开发 / 数据库 / 云计算 / 技术管理…

**形态**：每个目标 = 一棵带优先级的能力树（前置依赖 + 权重）。目标是导航，不是牢笼——可随时切换目标、或自由学不设目标。

## 附：完整学习旅程（愿景示例）

> 选定目标「后端工程师」，白板展开成长地图，绿色是会的、灰色是待学的。
>
> 打开工作区「学 HTTP」，与助教聊天，句子里 `DNS`、`缓存` 自动标注，悬停速查、快捷键派生子会话，会话在白板上长成关系树。
>
> 学完一段，点"生成笔记"，整个工作区被总结成学习资料，标出"HTTP 缓存你还没吃透"。
>
> 第二天，助教没等开口，弹出一道关于 DNS 的小测验——因为昨天刚学、记忆正好该巩固。答对了，白板上 DNS 节点从灰变绿。
>
> 一周后面试，助教已知道你薄弱在哪，从最虚处追问。答错，不批评，而是说"这属于 HTTP 缓存，我们去补一下"，直接带回那个工作区。
>
> 三个月后，打开成长回顾：一条曲线、一张越来越绿的地图、一本可翻阅的学习史。而这个老师，比你自己更了解你的学习。
