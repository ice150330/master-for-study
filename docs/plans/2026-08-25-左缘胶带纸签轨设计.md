# 左缘胶带纸签轨（TapeRail）替代左侧导航栏

> 日期：2026-08-25 · 状态：已与用户逐项对齐（七项拍板），实施中

## 背景与决策

会话页 18 轮精修 + 七页书签页头重构完成后，用户要求把模块导航整体挪到左侧页面渲染区之外，以胶带纸签形式呈现，替代现有左侧导航栏。经多轮问答拍板：

1. **形态**：左缘撕裂胶带签堆（复用 `--tape-torn` clip-path 与 `.session-tape-tab` 语言），签为横条、竖向堆叠，贴内容区左缘、占独立轨列（在渲染区之外，不与内容重叠）
2. **导航范围**：八页全部常显，「今日/学习/测验/洞察」四区降为小间隔（不再是一级导航）
3. **收起态**：纯图标（~44px）；悬停/聚焦整叠扇出显全名（宽度过渡，不出轨）
4. **当前页签**：加宽 + 墨底填充（`bg-foreground text-background`）+ 黄错位影 + **常显完整页名**（不悬停也展开）；轨宽即当前签宽（~104px）
5. **工具区**：工作区切换 / 搜索 / 设置 / 主题四钮收轨底（与导航签留间隔）
6. **顶部**：索引标签排删除；吸顶页头条保留（meta/filters/actions 三槽不变），标题（模块图标 + h1 + `page-context-title` testid）收编进页头条左侧
7. **chat 去重**：会话卡头部的工作区切换器去掉，唯一入口在轨底

移动端（<768）不变：底部区域导航 + 工具格，轨隐藏。

## 实施

1. `globals.css`：`.tape-rail` 轨列与 `.rail-tape` 签样式（竖叠横条、撕裂端、收起 44px、扇出 max-width 过渡、当前签墨底常显；四区间隔虚线小刻度）
2. `components/shell/TapeRail.tsx`（新，client）：导航签（`NAV_SECTIONS` 数据 + `NAV_ICONS`，Link 跳转带学习上下文 + `saveCurrentRouteScrollPosition`，`aria-label="主导航"` 保持）+ 轨底工具段（`WorkspaceSwitcher` + `SidebarTools` 适配竖排）
3. `PageShell`：收编页头条（删 `BookmarkBar.tsx` 的标签排，标题入头条；组件回归 server-safe）；`pageKey` → 图标 + 页名
4. `AppShell`：删除左 aside 侧栏，主区前插入 TapeRail；移动底部导航不动
5. `chat/SessionCard.tsx`：头部去 WorkspaceSwitcher
6. E2E 修正：shell-navigation（侧栏 196px 断言 → 轨宽断言；主导航可见性沿用）、accessibility-layout（Tab 序、24px 触达——签 44px ✓）、visual-baseline 截图
7. `DESIGN.md`（替换「索引标签书签页头」节为「左缘胶带纸签轨 + 吸顶页头条」）+ `CHANGES.md`
