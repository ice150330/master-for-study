## A. 动摇核心承诺（P0/P1.5）

### A1 · AI 老师跨会话失忆 —— 蓝图第一承诺未兑现 【P0 · ✅ 已交付 2026-08-24，`ad191d0`】

- **现象**：新开会话问老师，它不知道用户上周学过什么、哪里薄弱、面试错在哪。
- **根因**：`/api/chat` 系统提示词 = 术语标注指令 + 风格 + 深浅 + 本轮资源；对话上下文只有当前会话树前缀。`termMasteries` / `learningEvents` / 面试错题史从未注入提示词。
- **落地**：`getLearnerProfileSnapshot()` 聚合近期主题 + 薄弱概念，`learnerMemoryPrompt()` 注入系统提示词；`memory_injection` 设置开关（默认开），空画像不占提示词。

### A2 · 术语自动入队 = 复习队列灌水 + 标注无纠错 【P0 · ✅ 已交付 2026-08-24，`ba82c8c`】

- **现象**：一次长对话产出十几个 `[[术语]]` 全部进复习队列；标注错误/过度标注无处理入口。
- **落地**：`term_masteries.queue_status`（pending/active/dismissed，迁移 0016）——新概念默认待确认，Concept 轨道与复习页空态确认入队（单个/批量）；复习页跳过本次（+1 天）/ 降低频率（+30 天）/ 移出队列；术语高亮黑名单（「不再高亮」+ 解析降级）；逾期「先清最旧」引导。

### A3 · 多工作区破坏单源卡片 —— ~~产品决策项~~ 【前提有误，已撤销】

- **核实结论（2026-08-24）**：实施 A2 时发现 `terms` 表本就是**全局唯一**（name 全表约束，`upsertTerm` 按名跨工作区合并），`term_masteries` 亦按 termId 全局唯一——概念一直就是跨工作区单源，多工作区并未破坏单源卡片。本文初版"两个方向二选一"基于错误前提，作废。真正的工作区隔离边界在：会话 / 消息 / 复习卡（卡片表带 workspaceId）、笔记 / 资源 / 事件——即"学习过程按区分，概念全局共享"，这与蓝图单源卡片原则一致，无需迁移。

### A4 · 间隔重复只在"用户主动回来"时有效 【P0 · ✅ 已交付 2026-08-24，`03ed20e`】

- **现象**：无任何提醒机制；周末型用户回来面对逾期卡堆，体验是负罪感而非引导。
- **落地**：标题 `(N)` 到期徽标（5 分钟轮询、不冻结路由标题）+ 浏览器通知（授权后应用打开期间每日至多一次）+ 逾期引导文案；`/api/review?summary=1` 轻量端点。应用未打开不产生系统通知为本地 Web 的明确边界。

## C. 实用性短板（P2/P3）

1. **全局内容搜索**：顶栏只搜页面名；补 FTS5 或 SQLite LIKE 起步——"我上次在哪聊过 WAL"跨会话/笔记/资源检索。【P2 · ✅ 已交付 `a5c9bfb`，LIKE 起步，FTS5 留待量大后升级】
2. **冷启动**：新用户资源库空、无引导。最低配：首个工作区引导对话 + 资源种子若干。【P2】
3. **成本与异常感知**：token 用量展示（按会话/日）；DeepSeek 限流/欠费给出可区分的错误文案。【P2】
4. **工作区删除/归档**：只有增改切；补归档 + 删除（含数据 cascade 或导出后删）。【P2】
5. **学习时长统计**：对话阅读时间不入度量；补"会话停留近似"或滚动深度，标注为近似值。【P3】
6. **工作区切换体验**：整页 reload 丢输入；改为路由级状态保活或切换前暂存输入框。【P3】
7. **移动端**：维持既有"基础护栏"决策，不投入（记录在案，非目标）。【非目标】
