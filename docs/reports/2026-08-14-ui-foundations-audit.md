## 验收状态

- 浅色、深色、键盘焦点、Tooltip、Dialog、Toast 和内容状态均已真实渲染并截图。
- Dialog 支持焦点约束与 Escape 关闭；Popover、Dropdown Menu 和 Tooltip 均通过实际交互校验。
- `prefers-reduced-motion` 下全局动画与过渡缩短到近似即时，功能保持完整。
- `/dev/ui` 只在开发环境返回视觉页，生产环境走 `notFound()`，不进入正式导航。

## 视觉结论

1. 浅色主题使用灰白 Canvas 和白色工作面，紫色只承担主路径，青色承担掌握/加入，珊瑚色承担风险；同屏不再由一组紫色深浅主导。
2. 深色主题改为中性炭黑与深灰工作面，语义色提高明度但不铺满背景，长时间学习时比原深紫卡片堆更安静。
3. 按钮、字段、分段控制和图标按钮都使用 6px 左右的小圆角与稳定高度；焦点环在浅色、深色和弹层内均清晰可见。
4. Dialog 的背景降噪、内容标题、说明、字段与操作区形成明确顺序；Tooltip 同时响应键盘焦点，图标按钮不再依赖 `title`。
5. EmptyState 与 ErrorState 使用无外层卡片的分区表达；错误状态明确说明输入已保留，并给出单一重试动作。

## 现存边界

- 旧业务组件仍保留各自的按钮和表单类名，阶段 3 起按模块迁移，不在本阶段进行大范围机械替换。
- 顶部导航仍是旧结构，桌面工作台与窄屏溢出将在阶段 2 解决。
- 分析页和白板页仍使用旧卡片/画布表达，本阶段只确认新令牌没有造成视觉回退。
