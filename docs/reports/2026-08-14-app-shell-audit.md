## 视觉结论

1. 桌面端把原先顶栏中的八个同权模块改为“今日、学习、测验、洞察”四个区域，当前区域、当前页面和工具操作不再争抢同一行宽度。
2. 左侧导航使用低对比度分隔和浅色当前态，不将每个入口都做成胶囊；主工作区仍保留聊天卡片堆所需的连续宽度。
3. 顶部上下文条只展示区域、页面、本地工作区、搜索、设置和主题，形成稳定工具位置；搜索结果只包含真实可访问页面。
4. `/today` 当前只提供继续对话、到期复习和 SQL 实践三个真实入口，不展示未经数据支持的数量、时间或推荐理由。
5. 1024px 使用图标栏而非压缩文字；窄屏使用四区域底栏后，阶段 0 中由固定顶栏造成的 `446–626px` 文档宽度已消失。
