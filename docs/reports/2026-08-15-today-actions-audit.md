# 阶段 8：今日学习行动页验收

## 功能结果

- `/today` 由服务端实时读取 SQLite，不再使用固定的三条示例任务。
- “继续学习”引用最近活动且已有消息的会话，并通过 `session` 深链接打开准确会话；来源会说明是否对应最近学习事件。
- 到期复习读取 `term_masteries.due_at`，仅给出数量、首个概念和宽松时间范围。
- 薄弱练习使用现有掌握度难度排序，并把 Concept ID 传入实践模块。
- 未完成资源和最近笔记各保留一个行动，来源分别是资源状态队列和笔记时间。
- 每行只有一个紫色主操作；时钟图标只负责“今天稍后处理”，状态保存在本机 localStorage。
- 工作区完全无记录时只出现“从一个真实问题开始”；全部行动暂缓后显示可恢复完成态。

## 截图审查

截图位于 `data/ui-captures/08-today-actions/`，不进入 Git；使用与生产组件相同的开发数据夹具保证状态稳定。

- `first-use`：只有一个明确起步动作，无空统计或功能介绍。
- `normal`：继续、复习、练习、资源和笔记按行排列，来源与投入范围可扫描，主操作列对齐。
- `completed`：暂缓全部行动后显示克制的完成状态，并保留恢复入口。

三个 1440 × 900 状态无嵌套卡片、文字裁切、按钮位移或横向滚动。
