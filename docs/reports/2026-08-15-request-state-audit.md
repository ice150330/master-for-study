# 阶段 3：请求状态与竞态处理验收

## 验收范围

本阶段以 1440 × 900 桌面工作台为主验收面，通过 Playwright 拦截接口，稳定复现 400、500、超时、中止和重试，不依赖真实 DeepSeek 服务。

## 行为结果

| 场景 | 预期 | 结果 |
|---|---|---|
| 聊天接口 500 | 问题不丢失，显示原因和重试入口 | 通过 |
| 聊天重试成功 | 错误提示消失，回答正常进入消息流 | 通过 |
| 流式期间切换会话 | 旧请求中止，延迟响应不能覆盖新会话 | 通过 |
| 术语提取失败 | 保留已完成回答，仅提示增强步骤失败 | 通过 |
| 资源保存 500 | 标题、URL、关联项不清空 | 通过 |
| 复习提交 500 | 当前术语、答案面和评级入口不变化 | 通过 |
| 客户端超时 | 中止底层请求并返回 `REQUEST_TIMEOUT` | 通过 |

## 截图审查

截图位于 `data/ui-captures/03-request-states/`，该目录为本地验收产物，不进入 Git。

- `03-request-states-chat-500-desktop-1440x900.png`：错误紧邻输入区，原因、保留内容和重试动作形成一组，不遮挡消息。
- `03-request-states-chat-retry-success-desktop-1440x900.png`：重试后错误区域收起，输入区尺寸稳定，无布局跳动。
- `03-request-states-resource-500-desktop-1440x900.png`：错误位于资源表单内部，用户可直接修正或重试；标题和 URL 清晰保留。
- `03-request-states-review-500-desktop-1440x900.png`：错误位于卡片顶部，答案与四个评级按钮继续可见，没有覆盖主要内容。

视觉结论：四个状态均无文字重叠、裁切或页面级横向滚动；错误色仅用于局部反馈，没有把整个工作台染成警报状态。
